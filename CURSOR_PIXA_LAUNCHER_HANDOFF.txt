LIMITS TO COMMUNICATE
Mac launcher installation only; Linux/Windows builds are library previews. Editor updates are explicit; the user quits the app and selects Update. Launcher self-update is not implemented. Existing strict Ed25519 manifest API is not a configured production feed; live discovery uses HTTPS GitHub metadata plus independently verified Apple app signatures/publisher identity. No claim of complete editor feature parity follows from launcher installation.

The website launcher remains Coming soon until step 8/9. It must not advertise a nonexistent or unsigned launcher installer.
