Use the publisher's existing local Developer ID and Keychain notary profile. Do not export a .p12 or put an Apple password in a shell argument. Check free disk; never delete user data to make room.

python3 release-tools/macos_candidate.py pixafilm "/actual/path/PixaFilm.app" --identity "Developer ID Application: Luke Barger (945M5X4DY3)" --profile "PixaShop-Notary" --architecture universal --output "$HOME/Documents/PixaFilm-Release-0.1.1" --notices "/actual/path/Licenses"
