# PixaPDF Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Open a copy of a PDF you can safely experiment with. Check the page count and orientation.

## Make a first edit

Choose the task you need, such as reading, commenting or organizing pages. Confirm the target page or selection before applying a change.

## Keep your work organized

Keep an original copy before rearranging or removing pages. Review pages at a readable zoom after editing.

## Save and export

Save to a new file while learning. Reopen the result and check page order, visible content and any security settings you changed. If account access expires in a subscription preview, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
