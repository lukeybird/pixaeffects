# PixaFilm Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Import a few short clips and place them in a sequence. Work with copies of important footage.

## Make a first edit

Arrange clips on the timeline, trim their beginnings and ends, and preview the cuts. Listen to the audio as well as watching the image.

## Keep your work organized

Keep original media available at its original path. Use clearly named tracks and sequences so the project remains understandable.

## Save and export

Save the project separately from the rendered video. Preview the exported result from beginning to end before sharing it. If account access expires in a subscription preview, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
