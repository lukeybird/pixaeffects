# PixaInterface Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Create a small design with one screen or frame. Decide what the person using that screen should notice first.

## Make a first edit

Add shapes, text and interface elements, then adjust alignment and spacing. Use a consistent visual hierarchy.

## Keep your work organized

Name screens and layers clearly. Keep related elements together and reuse consistent styling where the editor supports it.

## Save and export

Save the editable design and preview the screens you plan to share. Check exported assets at their intended display size. If account access expires in a subscription preview, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
