# PixaAnything Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Choose software or files you own or are authorized to inspect. Begin with a small, clearly defined question.

## Make a first edit

Use the application's available exploration tools and read the evidence they return. Distinguish confirmed findings from guesses or missing information.

## Keep your work organized

Keep the project focused and review any action that would execute code, change files or affect another device before approving it.

## Save and export

Save the project and its findings. Test any new software you build in an isolated environment before using it with important data.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
