# PixaTexture Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Begin with a test model or project. Keep an untouched copy of the model and its original textures.

## Make a first edit

Choose a paint target and make a small brush stroke. Check the result on the model before painting a large area.

## Keep your work organized

Keep texture layers and channels organized. Check that you are painting the intended texture set.

## Save and export

Save the editable project before exporting textures. Inspect the exported maps in the program where you intend to use them. If account access expires in a subscription preview, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
