# PixaMaterial Starter Manual

by AIWebDesignFirm

Starter workflow and orientation; not a complete reference for every tool.

## Start a first project

Start with a small material graph and inspect its preview. Build up complexity gradually.

## Make a first edit

Connect a small number of nodes, adjust a parameter and watch how the result changes. Change one thing at a time while learning.

## Keep your work organized

Keep the graph readable and identify the final outputs. Avoid unnecessary complexity until the basic material works.

## Save and export

Save the editable graph or package. Export the outputs you need and check them in the destination application. If account access expires in a subscription preview, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

## Your account

Use Your account in the Pixa footer to open the account connection window. Passwords and payment details stay in your browser. Only approve an activation code displayed on your own device. This unpublished build tests account connectivity; editing enforcement and persistent sign-in are not yet release-ready.

## Updates

Use Updates in the Pixa footer to see update availability. Updates are deliberately disabled until the publisher configures a signed release feed and completes platform installation tests. You do not need to install an ArtCraft update for a Pixa product.
