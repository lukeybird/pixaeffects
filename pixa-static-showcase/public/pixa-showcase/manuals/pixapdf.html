Start a first project

Open a copy of a PDF you can safely experiment with. Check the page count and orientation.

Make a first edit

Choose the task you need, such as reading, commenting or organizing pages. Confirm the target page or selection before applying a change.

Keep your work organized

Keep an original copy before rearranging or removing pages. Review pages at a readable zoom after editing.

Save and export

Save to a new file while learning. Reopen the result and check page order, visible content and any security settings you changed. If the device access refresh fails, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

Your account

Use Your account in the Pixa footer to connect this device. Pixa is free early access with no card requirement and no scheduled account expiration. Only approve the code displayed on your own device. Device access refreshes online; a disconnected, revoked or signed-out device must reconnect. Your files remain local.

Updates

Use Updates in the Pixa footer to check the Pixa publisher feed. On Mac, download the candidate, save your work and choose Install and restart. The app checks the installer digest, Apple publisher signature, bundle identity and Gatekeeper before replacement. A canceled editor-close prompt cancels the pending restart. Windows and Linux open the Pixa download page. No update is offered until a matching publisher release exists.

Find your way around

The menu bar and editor panels contain the main controls. Use the existing workspace controls to show a hidden panel. Manual and Quick tour in the Pixa footer reopen this help without changing the project.

Undo and safe experiments

Use Undo to reverse a normal document edit, and Redo to restore it. Keep an original project or duplicate before destructive operations. Undo does not reverse an external file deletion, a published upload or every background operation.

Linked files and portability

An editable project may refer to media, fonts, textures or other external files. Keep those resources alongside your project in a stable folder. Copy the complete folder when moving computers and reopen it before removing the original.

Working with another application

Save a native editable copy before exporting an interchange format. Features such as effects, fonts and linked resources may differ in another application. Reopen exported files in the destination application before relying on them.

Recovery and backups

Save regularly and keep a separate backup of important projects and original media. Recovery copies contain committed project state; unfinished text fields, external files and background tasks may need separate attention. Restore into a new project or folder rather than overwriting the original.

Troubleshooting

For missing content, check the active document, selected object, visible panels, layers and linked-file paths. For account problems, reconnect in Your account. For failed updates, keep the existing application and use the verified Pixa download page; do not disable operating-system security checks.

Export a PDF

Export a PDF to a supported editable, image or text format. Choose the output appropriate to the receiving app; conversion may change layout, fonts or interactive content. Some export formats are still planned.

Fill & Sign

Add text, marks, dates, initials or a signature appearance to a form. A drawn signature appearance is separate from cryptographically signing with a certificate.

Edit a PDF

This tool family is still marked planned in the source. Do not rely on general PDF content editing being complete. Use the original authoring document for unsupported changes.

Create a PDF

Create a new PDF from supported input. Check page dimensions, orientation and font appearance in the resulting PDF before sharing it.

Combine files

Combine supported files into one PDF. Review their order and page orientation, then save to a new destination rather than overwriting the input files.

Organize pages

Use the page overview to arrange, rotate, insert, extract or remove supported pages. Review the resulting page order and keep an original before deleting pages.

Add comments

Add review comments and annotations. These communicate proposed changes; they do not necessarily modify the underlying page content.

Scan & OCR

Use the available scan and OCR controls to bring image content into a searchable workflow. OCR can misread text; inspect names, numbers and exported text.

Protect a PDF

This tool family is still marked planned in the source. Do not assume a document has encryption or access restrictions merely because this panel is visible.

Redact a PDF

Use the dedicated redaction workflow for sensitive content. A black drawing or annotation is not a substitute for applied redaction. Retain a private original and inspect the sanitized copy before sharing.

Compress a PDF

Create a smaller PDF using supported compression options. Inspect small text and images afterward, especially when preparing a print document.

Prepare a form

Create and arrange supported form fields, then test their values and tab order. Save the editable form separately from a completed or flattened copy.

Add a stamp

Add a stamp annotation to the document. Stamps are visual marks; they do not by themselves prove authorship or certificate validity.

Use a certificate

Use the supported certificate controls for digital-signature workflows. Manage certificate credentials privately; signature trust and the validity of document content are separate questions.

Use print production

This tool family is still marked planned in the source. Do not treat the available UI as evidence of complete professional prepress validation.

Measure objects

Measure supported objects on a PDF page. Set and confirm the scale first; measuring a scan without a known scale does not establish real-world dimensions.

Compare files

Compare two PDF versions to inspect differences. Review the actual changed pages; a comparison result does not establish that every semantic difference was detected.

Use guided actions

Use guided actions for supported multi-step processing. Check input and output locations and keep originals before running a batch.

Prepare for accessibility

Inspect and prepare supported accessibility structures. Machine checks alone do not establish accessible reading order or usable alternative text; review the document with its intended reading workflow.

Apply PDF standards

Use supported PDF standards checks or conversion controls. Confirm the requested profile and read reported limitations before describing the output as conforming.

Add search index

This tool family is still marked planned in the source. Basic document search and a generated multi-document search index are different capabilities.

Use JavaScript

This tool family is still marked planned in the source. Do not assume PDF scripts or scripted form behavior will run as they do in another PDF application.

AI assistant

The AI assistant requires an optional provider. This is not a bundled unlimited AI service; provider availability and setup determine which actions can run.
