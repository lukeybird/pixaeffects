Start a first project

Create a short document or open a copy of an existing one. Type a few paragraphs before applying extensive formatting.

Make a first edit

Select text to change its formatting. Use paragraph and document controls for spacing and page layout rather than repeated spaces or blank lines.

Keep your work organized

Use consistent headings and styles. Review page breaks, lists and tables as the document grows.

Save and export

Save an editable document. If exporting a PDF or another format, reopen it and check pagination and text layout. If the device access refresh fails, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

Your account

Use Your account in the Pixa footer to connect this device. Pixa is free early access with no card requirement and no scheduled account expiration. Only approve the code displayed on your own device. Device access refreshes online; a disconnected, revoked or signed-out device must reconnect. Your files remain local.

Updates

Use Updates in the Pixa footer to check the Pixa publisher feed. On Mac, download the candidate, save your work and choose Install and restart. The app checks the installer digest, Apple publisher signature, bundle identity and Gatekeeper before replacement. A canceled editor-close prompt cancels the pending restart. Windows and Linux open the Pixa download page. No update is offered until a matching publisher release exists.

Find your way around

The menu bar and editor panels contain the main controls. Use the existing workspace controls to show a hidden panel. Manual and Quick tour in the Pixa footer reopen this help without changing the project.

Undo and safe experiments

Use Undo to reverse a normal document edit, and Redo to restore it. Keep an original project or duplicate before destructive operations. Undo does not reverse an external file deletion, a published upload or every background operation.

Linked files and portability

An editable project may refer to media, fonts, textures or other external files. Keep those resources alongside your project in a stable folder. Copy the complete folder when moving computers and reopen it before removing the original.

Working with another application

Save a native editable copy before exporting an interchange format. Features such as effects, fonts and linked resources may differ in another application. Reopen exported files in the destination application before relying on them.

Recovery and backups

Save regularly and keep a separate backup of important projects and original media. Recovery copies contain committed project state; unfinished text fields, external files and background tasks may need separate attention. Restore into a new project or folder rather than overwriting the original.

Troubleshooting

For missing content, check the active document, selected object, visible panels, layers and linked-file paths. For account problems, reconnect in Your account. For failed updates, keep the existing application and use the verified Pixa download page; do not disable operating-system security checks.

Home

Use Home for text and paragraph formatting. Select existing text before applying a change; with only a caret, some formatting affects new text instead.

Insert

Use Insert to add document objects such as tables, pictures and other supported content. Select the inserted object to reveal its contextual formatting controls.

Draw

Use Draw for ink marks rather than ordinary typed paragraphs. Keep important text as editable text when it needs search, copying or later revision.

Design and Layout

Design controls document styling; Layout controls page geometry such as margins, orientation and columns. Check all affected pages before exporting.

References

Use References for supported document references and navigation structures. Update generated content after editing headings or source information.

Mailings

Use Mailings for supported merge workflows. Check the source data and preview records before producing final copies; keep a separate editable master.

Review

Use Review to inspect proofing, comments and revisions. Review proposed changes individually when meaning matters; spell checking does not establish factual correctness.

View

Change the document view and visible navigation controls in View. Reading settings change how you view the document; page layout still determines its printed result.

Developer and Zotero

Developer and Zotero expose specialist controls and integrations. External integrations may need their own installation or setup; an inactive control does not indicate that its dependency is bundled.

Contextual formatting

Selecting a table, picture, shape, equation, chart or SmartArt object exposes its relevant contextual tab. Return to the text caret for ordinary text editing.
