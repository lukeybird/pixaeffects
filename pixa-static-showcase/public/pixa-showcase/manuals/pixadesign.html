Start a first project

Create a document with the page dimensions you need. Begin with one page before building a large publication.

Make a first edit

Place text and images into the layout. Adjust alignment, spacing and text flow so the page reads clearly.

Keep your work organized

Use consistent styles and keep linked images accessible. Review every page for missing images or overflowing text.

Save and export

Save the editable layout. Export a separate PDF when needed, then inspect its pages before sending it to print or publication. If the device access refresh fails, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

Your account

Use Your account in the Pixa footer to connect this device. Pixa is free early access with no card requirement and no scheduled account expiration. Only approve the code displayed on your own device. Device access refreshes online; a disconnected, revoked or signed-out device must reconnect. Your files remain local.

Updates

Use Updates in the Pixa footer to check the Pixa publisher feed. On Mac, download the candidate, save your work and choose Install and restart. The app checks the installer digest, Apple publisher signature, bundle identity and Gatekeeper before replacement. A canceled editor-close prompt cancels the pending restart. Windows and Linux open the Pixa download page. No update is offered until a matching publisher release exists.

Find your way around

The menu bar and editor panels contain the main controls. Use the existing workspace controls to show a hidden panel. Manual and Quick tour in the Pixa footer reopen this help without changing the project.

Undo and safe experiments

Use Undo to reverse a normal document edit, and Redo to restore it. Keep an original project or duplicate before destructive operations. Undo does not reverse an external file deletion, a published upload or every background operation.

Linked files and portability

An editable project may refer to media, fonts, textures or other external files. Keep those resources alongside your project in a stable folder. Copy the complete folder when moving computers and reopen it before removing the original.

Working with another application

Save a native editable copy before exporting an interchange format. Features such as effects, fonts and linked resources may differ in another application. Reopen exported files in the destination application before relying on them.

Recovery and backups

Save regularly and keep a separate backup of important projects and original media. Recovery copies contain committed project state; unfinished text fields, external files and background tasks may need separate attention. Restore into a new project or folder rather than overwriting the original.

Troubleshooting

For missing content, check the active document, selected object, visible panels, layers and linked-file paths. For account problems, reconnect in Your account. For failed updates, keep the existing application and use the verified Pixa download page; do not disable operating-system security checks.

Selection Tool

Select whole frames or objects, then move or resize them. Use this for arranging the page without editing individual path points. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: V. Custom keymaps may differ.

Direct Selection Tool

Select an individual anchor or segment inside a path. Use this when the shape itself needs adjustment. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: A. Custom keymaps may differ.

Page Tool

Select and adjust a page rather than a frame on it. Use this for page-level geometry changes. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Shift+P. Custom keymaps may differ.

Gap Tool

Adjust the space between neighboring frames. Use this when the gutter between objects needs to change. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: U. Custom keymaps may differ.

Content Collector Tool

Collect selected content for reuse. Use the content conveyor to gather items before placing them elsewhere. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: B. Custom keymaps may differ.

Content Placer Tool

Place content from the content conveyor. Use this after collecting items that you want to reuse in another position. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: B. Custom keymaps may differ.

Type Tool

Create a text frame or edit text inside one. Click within existing text to place the insertion point. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: T. Custom keymaps may differ.

Type on a Path Tool

Place and edit text that follows a path. Use an existing path as the text baseline. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Shift+T. Custom keymaps may differ.

Vertical Type Tool

Create or edit vertically arranged text. Use this when a layout needs vertical text flow. Find this in the Tools panel; grouped tools share a flyout.

Vertical Type on a Path Tool

Arrange vertical text along a path. Select the path you want the text to follow. Find this in the Tools panel; grouped tools share a flyout.

Line Tool

Draw a straight line segment. Use the stroke controls to change its appearance. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: \. Custom keymaps may differ.

Pen Tool

Build a precise path point by point. Click for corners and drag when creating curved segments. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: P. Custom keymaps may differ.

Add Anchor Point Tool

Add an anchor to an existing path. Add points only where you need more control over the outline. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: =. Custom keymaps may differ.

Delete Anchor Point Tool

Remove an anchor from an existing path. Use this to simplify an outline without deleting the entire object. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: -. Custom keymaps may differ.

Convert Direction Point Tool

Change how a path passes through an anchor. Use direction handles to adjust a corner or curve. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Shift+C. Custom keymaps may differ.

Pencil Tool

Draw a freehand path. Use this for organic outlines rather than point-by-point construction. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: N. Custom keymaps may differ.

Smooth Tool

Reduce irregularities along a path. Work over an existing outline to make its curve smoother. Find this in the Tools panel; grouped tools share a flyout.

Erase Tool

Erase part of an existing path. Use this for removing unwanted sections rather than deleting the whole object. Find this in the Tools panel; grouped tools share a flyout.

Rectangle Frame Tool

Draw a rectangular frame intended to hold placed content. Use it as a placeholder before placing an image. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: F. Custom keymaps may differ.

Ellipse Frame Tool

Draw an elliptical content frame. Use it for an oval image crop or placeholder. Find this in the Tools panel; grouped tools share a flyout.

Polygon Frame Tool

Draw a polygonal content frame. Use it when placed artwork needs a polygon-shaped boundary. Find this in the Tools panel; grouped tools share a flyout.

Rectangle Tool

Draw a rectangular shape. Apply a fill, stroke or both for backgrounds, borders and graphic elements. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: M. Custom keymaps may differ.

Ellipse Tool

Draw an elliptical shape. Use it for circles, badges and other rounded page elements. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: L. Custom keymaps may differ.

Polygon Tool

Draw a polygonal shape. Adjust its shape settings for the number of sides you need. Find this in the Tools panel; grouped tools share a flyout.

Scissors Tool

Split a path at a chosen point. Use this to turn a continuous outline into separate segments. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: C. Custom keymaps may differ.

Free Transform Tool

Transform a selected object using its bounding controls. Use it for interactive size and orientation adjustments. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: E. Custom keymaps may differ.

Rotate Tool

Rotate a selected object around a reference point. Use this when its angle needs to change. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: R. Custom keymaps may differ.

Scale Tool

Resize selected content. Check whether you want proportional scaling before committing a size change. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: S. Custom keymaps may differ.

Shear Tool

Slant selected content. Use this for an angled shape while keeping its opposite sides parallel. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: O. Custom keymaps may differ.

Gradient Swatch Tool

Control a gradient's direction and span on an object. Choose gradient colors in the associated color controls. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: G. Custom keymaps may differ.

Gradient Feather Tool

Apply or adjust a gradual fade in transparency. Use this when content should blend softly into the page. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Shift+G. Custom keymaps may differ.

Note Tool

Add an editorial note. Use notes for instructions or review comments separate from the visible page artwork. Find this in the Tools panel; grouped tools share a flyout.

Color Theme Tool

Collect a color theme from artwork. Use the resulting colors to build a consistent page palette. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Shift+I. Custom keymaps may differ.

Eyedropper Tool

Sample appearance attributes from existing artwork. Use it to repeat an established visual style. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: I. Custom keymaps may differ.

Measure Tool

Measure a distance or angle between points. Use it to inspect geometry before adjusting your layout. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: K. Custom keymaps may differ.

Hand Tool

Pan the document view. Moving the view does not move page objects. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: H. Custom keymaps may differ.

Zoom Tool

Change the view magnification. Zooming changes how closely you inspect the page, not its output dimensions. Find this in the Tools panel; grouped tools share a flyout. Default shortcut: Z. Custom keymaps may differ.
