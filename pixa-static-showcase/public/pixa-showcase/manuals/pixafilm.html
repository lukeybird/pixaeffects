Start a first project

Import a few short clips and place them in a sequence. Work with copies of important footage. Help → PixaFilm User Manual (also F1) opens this offline guide. Help → Quick Tool Tour explains all 17 timeline tools with Next, Back, Finish and Escape; visible tool groups are highlighted without changing your active tool or project.

Make a first edit

Arrange clips on the timeline, trim their beginnings and ends, and preview the cuts. Listen to the audio as well as watching the image.

Keep your work organized

Keep original media available at its original path. Use clearly named tracks and sequences so the project remains understandable.

Save and export

Save the project separately from the rendered video. Preview the exported result from beginning to end before sharing it. If the device access refresh fails, keep the app open and use Save recovery copy to choose a destination. Reconnect before closing if you have unfinished text fields or background operations. Open the recovered native files in the editor after reconnecting; retain the original files.

Your account

Use Your account in the Pixa footer to connect this device. Pixa is free early access with no card requirement and no scheduled account expiration. Only approve the code displayed on your own device. Device access refreshes online; a disconnected, revoked or signed-out device must reconnect. Your files remain local.

Updates

Use Updates in the Pixa footer to check the Pixa publisher feed. On Mac, download the candidate, save your work and choose Install and restart. The app checks the installer digest, Apple publisher signature, bundle identity and Gatekeeper before replacement. A canceled editor-close prompt cancels the pending restart. Windows and Linux open the Pixa download page. No update is offered until a matching publisher release exists. PixaFilm checks its own publisher feed in the background once at startup. A matching available update opens the Updates window. Downloading and installation still require your choice.

Find your way around

The menu bar and editor panels contain the main controls. Use the existing workspace controls to show a hidden panel. Manual and Quick tour in the Pixa footer reopen this help without changing the project.

Undo and safe experiments

Use Undo to reverse a normal document edit, and Redo to restore it. Keep an original project or duplicate before destructive operations. Undo does not reverse an external file deletion, a published upload or every background operation.

Linked files and portability

An editable project may refer to media, fonts, textures or other external files. Keep those resources alongside your project in a stable folder. Copy the complete folder when moving computers and reopen it before removing the original.

Working with another application

Save a native editable copy before exporting an interchange format. Features such as effects, fonts and linked resources may differ in another application. Reopen exported files in the destination application before relying on them.

Recovery and backups

Save regularly and keep a separate backup of important projects and original media. Recovery copies contain committed project state; unfinished text fields, external files and background tasks may need separate attention. Restore into a new project or folder rather than overwriting the original.

Troubleshooting

For missing content, check the active document, selected object, visible panels, layers and linked-file paths. For account problems, reconnect in Your account. For failed updates, keep the existing application and use the verified Pixa download page; do not disable operating-system security checks.

Selection Tool

Select, move and trim clips in the timeline. Drag a clip body to move it or an edge to adjust a cut.

Track Select Forward Tool

Select clips from the clicked position forward so a group of later edits can move together.

Track Select Backward Tool

Select clips before the clicked position for a coordinated timeline move.

Ripple Edit Tool

Trim a clip while closing or opening the adjacent timeline gap; later clips can shift.

Rolling Edit Tool

Move a cut between neighboring clips while keeping their combined duration unchanged.

Rate Stretch Tool

Change a clip's timeline duration by changing playback speed. Check the resulting motion and audio.

Remix Tool

Adjust music to fit a target duration. Listen to the transitions before exporting.

Razor Tool

Cut a clip at the clicked timeline position. Select the pieces afterward to move or remove them.

Slip Tool

Change which source frames appear inside a clip without moving its timeline boundaries.

Slide Tool

Move a clip while trimming its neighboring clips to preserve the surrounding sequence length.

Pen Tool

Add or adjust clip keyframes to change properties over time.

Rectangle Tool

Draw a rectangular graphic or mask in the viewer.

Ellipse Tool

Draw an elliptical graphic or mask in the viewer.

Hand Tool

Pan the timeline or viewer without moving project content.

Zoom Tool

Change the timeline or viewer magnification; this does not change export resolution.

Type Tool

Create or edit horizontal text for titles and graphics.

Vertical Type Tool

Create or edit text arranged vertically.
