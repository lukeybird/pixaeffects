# PixaCut modifications

Modified locally on 2026-11-14 from Nuzky commit 13dec1d70da91b5506ccceec3e05b275de708314. License: GPL-3.0-or-later. Original copyright and license notices are retained. This is an alpha branding prototype, not an endorsed upstream release or a tested native PixaCut installer. No repository, website or public release has been published.

Display branding, app identity/icon, default storage/credentials/IPC/MCP namespace, local quick guide and update/support routing changed. Editing algorithms and document schema are retained. See PIXACUT_STATUS.json for precise test limits. Existing upstream feedback/updater flows need adaptation to the intentionally disabled publisher configuration before a release gate can pass.
